# Project Name:BookNook – A Small Online Library
BookNook is a modern library and book-sharing web application that helps readers discover books, share their own collections, and keep track of borrowing activity in one convenient place.

**Live site URL:https://booknook-frontend-ecru.vercel.app/

Feature-
- Browse the latest arrivals and explore books by category.
- View detailed book information, including author, cover, description, and availability.
- Register or sign in to manage your personal BookNook profile.
- Add books to the library and manage books in your collection.
- Track borrowed books and review borrowing status through a personalized dashboard.
- Enjoy a responsive, accessible interface designed for desktop and mobile readers.
